# Melo Jurídico

PRD — SITE FERNANDO MELO | ADVOGADO TRABALHISTA

1. IDENTIDADE DO PROJETO

Nome: Fernando Melo
Atuação: Advogado Trabalhista
Segmento: Advocacia / Direito do Trabalho
Localização: Presidente Prudente – SP

Objetivo

Desenvolver um site institucional sofisticado, moderno, minimalista e premium, posicionando Fernando Melo como um profissional de advocacia trabalhista sério, confiável e preparado para atender clientes que buscam orientação jurídica.

O site deve transmitir imediatamente:

Autoridade

Confiança

Segurança

Sofisticação

Profissionalismo

Discrição

Atendimento personalizado

A experiência deve fugir completamente do visual comum de escritórios jurídicos.

2. CONCEITO

"Autoridade sem excessos."

O design deve utilizar poucos elementos, porém muito bem trabalhados.

A sensação desejada é de:

Escritório boutique + advocacia contemporânea + alto padrão.

Não criar um site cheio de textos jurídicos.

A página deve utilizar:

tipografia premium

grandes espaços vazios

imagens profissionais

contraste elegante

animações discretas

linhas finas

composição editorial

detalhes sofisticados

3. DIREÇÃO VISUAL

Estilo

Minimalista, editorial e sofisticado.

Referências visuais:

escritórios de advocacia premium

escritórios boutique

marcas de luxo

arquitetura contemporânea

revistas jurídicas sofisticadas

Evitar

azul jurídico genérico

excesso de dourado

martelo da justiça gigante

balança da justiça como elemento principal

imagens clichês de tribunais

excesso de ícones

banners promocionais

visual de site antigo

excesso de caixas e cards

4. PALETA DE CORES

Criar uma identidade predominantemente neutra.

Base

Off-white / Ivory

Para fundos principais.

Contraste

Preto / Grafite profundo

Para títulos e elementos de autoridade.

Cor secundária

Cinza quente / Taupe

Para áreas secundárias.

Detalhe premium

Um tom extremamente discreto de:

Dourado envelhecido / Champagne

Utilizar somente em pequenos detalhes.

Exemplo:

linhas

pequenos indicadores

ícones

detalhes de hover

Nunca utilizar dourado em excesso.
